# Robi 整合實驗記錄 v0.3.11

本版新增離線圖表報告、記錄狀態醒目提醒與設定規劃圖。沿用既有馬達流程、資料格式與校正方式。

雙擊 `start_windows.bat` 開啟。依賴未安裝時先執行 `install_windows.bat`。不需要重新燒錄STM32；原韌體與通訊封包格式沿用已驗證版本。

## 每輪獨立資料夾

在「實驗／裝置設定 → 實驗」可填本輪實驗名稱，例如「槳A_正轉」。留空時以轉速清單命名。

每輪建立「名稱_REAL或SIMULATION_日期時間」子資料夾，內含：

- data.csv：原始時間序列與事件。
- data.json：本輪設定、倍率與零點。
- data_summary.csv：通道統計摘要。
- data_stages.csv：每個轉速點一列。
- data_report.html：白底圖表報告，雙擊用瀏覽器離線開啟；也可在主畫面按「開啟圖表報告」。

主畫面「輸出資料夾」開最近一輪；裝置設定視窗「開啟全部實驗」開根目錄。舊版散放的檔案不搬動。

## 最近30秒趨勢

RPM、CH1及CH2的小曲線只繪製實際收到的數值。力規倍率未知時，趨勢以原始count顯示；校正或單位變更後清空舊歷史。未開始或無有效資料時不產生裝飾曲線。曲線不改變正式CSV與切段邏輯。

## 主畫面

- 上方：模式、馬達與力規連線狀態、記錄狀態、開始測試與STOP。
- 主要監看：RPM儀表、CH1／CH2換算值、原始值、資料新鮮度。
- 同區流程：任務名稱、等待／執行／完成狀態、同列時間條。啟動／到速／感測器檢查的時間是等待上限，不保證時間到就成功。
- 故障燈：依韌體回報顯示；FAULT_OVER需確認清除。斷線時故障未知。
- 重要讀值：板端V／Wo／溫度／Id／Iq；電供V／Imotor／Wi／設定電壓／限流；即時推力功率比；未接入的溫度保留空值。
- 底部：最新操作與錯誤。完整紀錄另開視窗。

常用兩組轉速流程可在一個螢幕查看，不設主畫面捲軸。依實際字體與螢幕尺寸測量視窗，較矮螢幕自動縮成緊湊布局。長清單顯示目前附近的三個轉速點與共用流程，按「完整清單」查看全部。

## 力規持續監看

1. 實機前取消模擬，關閉其他占用COM5／COM6的程式。
2. 按馬達連線，會自動開啟設定中已啟用的力規監看。也可不連馬達，獨立按「開始力規讀取」。開啟力規不發出馬達啟動命令。
3. 按鈕切換為「停止力規讀取」。讀取中顯示即時；過久無資料顯示資料過期，錯誤顯示通訊異常。
4. 正式測試使用同一個力規執行緒與連接埠；開始記錄與結束記錄不重開COM。測試結束、按STOP停止馬達後，力規仍持續監看。
5. 只有手動停止力規或關閉程式才釋放力規埠。停止後留最後值並明確標示保留值。正式實驗期間停讀鍵鎖定；要停止馬達請按STOP。

USB重新插拔若改變COM埠，先停讀，再在裝置設定更新。Access denied表示Windows拒絕開埠；關閉其他占用程式，必要時在馬達已停穩的情況下重新插拔力規USB。

## 設定與校正

「實驗／裝置設定」分頁調整轉速、時間、COM及電供，按套用才生效。電供仍只在正式測試啟用時擷取，不會設定輸出或自動開電供。

「力規校正」獨立視窗：

- CH1預設推力N，倍率0.01，原始零點0。
- CH2預設扭矩Nm，倍率0.001，原始零點0。載入舊設定會保留其中的明確倍率，可在校正視窗查看。
- 換算=(原始值−原始零點)×倍率；僅軟體換算，不改寫變送器。
- 兩點校正填回面板後，另按「套用設定」。校正套用不停止讀取、不重開連接埠。以第三個已知負載驗證。
- 原始值、倍率、原始零點、換算值皆保存。正式記錄期間鎖定校正及設定。
- 通訊參數變更需先停止力規；校正參數可在待命監看時套用。
- 按儲存設定保存，下一次載入。可載入舊版JSON，缺少零點時採0，缺少其餘欄位採預設。

## 正式測試

先確認兩通道對施力有反應。馬達應IDLE／無故障／SPEED模式。按開始測試後，所有已啟用感測器必須取得新資料，才進入基線與啟動。保留原本1500 rpm Rev-up、到速確認、各組定時停留及停機後記錄；未加入力規穩定判斷。

STOP不等於機械停穩，須目視確認。未確認停止、故障、資料過期或通訊失敗會留下事件。

每輪輸出：原始CSV、設定JSON、summary CSV、stages CSV與圖表報告HTML。原始CSV是一筆一個裝置讀值；stages每個轉速點一列。監看但未正式測試的讀值不存CSV。

即時gf/W使用最新有效力規與電供讀值估算，非同步取樣；正式組平均看stages。未接電供或倍率未知就留空，不用Pilot功率冒充輸入功率。

## 實機限制

熱電偶、環境溫度與手動組態欄位仍待後續整合。板端溫度不宣稱是MCU或線圈真實溫度。Windows實體USB、字體與驅動仍需現場確認。

## 圖表報告與舊紀錄

記錄結束並關閉原始 CSV 後，背景產生 data_report.html。報告包含同時間軸的轉速／推力／扭矩圖、各組全段與最後最多30秒平均、每30秒分段、啟動前與停機後末段基準比較、電氣／溫度／原始計數，以及取樣品質與事件。未接入的讀值顯示缺值。大量資料只為顯示保留分桶極值，統計使用完整量測，不平滑或覆寫原始資料。

「末段」不是自動穩定判斷；全段平均仍維持既有輸出邏輯。報告另列末段推力減啟動前平均，僅供比較，不改寫原始值。不同設備非同步取樣。Motor Pilot功率不視為獨立軸功率。

舊紀錄：雙擊 generate_report_windows.bat，選取原始 data.csv（同資料夾保留對應 data.json）。也可命令列執行 `py -3 report_cli.py "完整路徑\data.csv"`。此工具只讀檔，不開啟任何設備。報告為單檔，不需要網路或新增套件。可使用瀏覽器列印另存PDF。

## 實驗狀態提醒

主畫面醒目橫幅及視窗標題區分：待命、實驗中、停止確認、停機後仍在記錄（剩餘秒數）、記錄完成、實驗中止。進入停機後及記錄結束時呼叫系統提示音，是否出聲由系統音效設定決定。結束橫幅持續保留；不以最後讀值仍更新判斷是否在存檔。提示不宣稱槳葉已機械停穩。

## 設定中的流程圖

實驗設定頁下方會隨尚未套用的輸入更新轉速／記錄時間規劃圖，按「套用設定」才改變設定。短變速段為易讀放寬顯示，非等比例時間軸。總記錄固定時間不含檢查、啟動至1500rpm、到速確認與停止確認，實際時間較長；無效輸入不顯示舊的有效圖。

## v0.3.21 力規歸零與方向換算

- 實機馬達連線、無故障 IDLE、回授 0 rpm、未記錄且力規正在讀取時，可在 CH1 或 CH2 卡片按「歸零」。確認無外力後，程式用近期至少三筆穩定原始計數的平均更新該通道軟體零點。最大值與最小值差超過 2 count 時會拒絕。歸零不寫入力規硬體。若要保留到下次開啟，請在裝置設定儲存。
- 推力按裝法換算（正裝 −1、反裝 +1）。扭矩按槳葉標示旋向換算（CW −1、CCW +1）。反裝 CW 依台架約定，待實測核對。未選裝法或旋向時保留量測方向。
- 讀值卡大字與即時曲線顯示方向換算後的值，7 pt 小字顯示校正後、方向換算前的原量測。HTML 報告使用該輪記錄的係數。CSV 保留原計數、零點與原量測，JSON 保存方向係數。舊紀錄沒有係數時，補產報告會保留原量測方向。

## v0.3.22 PID／PLL 板端參數

從左側「裝置與螺旋槳 → PID／PLL」開啟。實機連線後按「讀取板端」，可查看 Speed PI（含 Kp／Ki 除數）、Iq／Id PI、Observer C1／C2、PLL PI 與唯讀 Torque Reference 原始值。數值使用板端整數格式，除數顯示為 2 的次方值。

無故障 IDLE、回授 0 rpm、未記錄時可選擇單一參數、修改並寫入。寫入前先比對原值，寫入後立即讀回。寫入狀態未確認時，須先重新讀取才可開始實驗。這些操作修改板端運行參數，沒有 Flash 儲存步驟。連線期間操作過 PID／PLL 讀取後，每輪實驗開始前會再讀回一次，存入 data.json，並在 HTML 報告列出。
