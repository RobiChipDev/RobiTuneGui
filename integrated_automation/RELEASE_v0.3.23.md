# v0.3.23：PID／PLL 介面改版

日期：2026-11-05（Asia/Taipei）。基於 v0.3.22；原版保留供回復。

## 變更

- Motor Pilot 風格雙分頁：Currents / Speed、Observer / PLL；Speed、Iq、Id 分組。
- 各列分開顯示板端讀值、待寫入值、寫入按鈕及狀態；數字放大、白底藍色重點。
- ＋／− 每次調整 1，只改輸入值，不送指令；Speed divisor 使用 1–32768 的 2 次方選單。
- Torque Reference 保持 raw／唯讀；Observer 保留負號；未讀取顯示 —，不預填截圖數值。
- 一次只寫一項，沿用原讀回驗證與 Controller 安全檢查；確認視窗後另檢查快照是否改變。
- 單項寫入回覆保留其他欄位尚未送出的編輯；停止／斷線／失敗造成快照清空時清除全部輸入，要求重讀。
- 僅更動 pid_dialog.py、app.py／controller.py 版本字串，新增 test_pid_dialog.py；未改協定、換算、流程與韌體。

## 使用

解壓到獨立資料夾，沿用 install_windows.bat／start_windows.bat。從主畫面開啟 PID／PLL，讀取板端後，編輯所需欄位並按該列「寫入」。彈窗顯示舊值→新值；驗證完成前不送第二筆。

板端讀值是最近一次快照，不是持續輪詢。待寫入值可先編輯，但實際寫入仍須實機連線、無故障 IDLE、0 rpm、未記錄。新數值不自動存入 Flash。

## 現場介面驗收／回復

先以未連線狀態開啟視窗，確認兩分頁、負數欄寬、全部按鈕與底部狀態可見；確認未讀取時欄位鎖定。不同 DPI 各檢查一次。之後依授權另做板端實測，不以模擬通過代替。

若排版不符現場環境，關閉新版，回到原 v0.3.22 資料夾啟動。原始 v0.3.22 壓縮包與資料保持原樣，不需回刷韌體。
